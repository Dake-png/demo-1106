# 伤害修饰体系

> 模块化原则：Effect / 装备 / 武器 三个子模块各自独立成表，一个条目 = 一条数据。
> 新增 = 加一条；删除 = 删一条；改数值 = 改一条。条目之间互不引用，不改逻辑代码。

## 0. 总则

### 0.1 计算顺序（固定）
    基础面板 → 加算区 → 乘算区 → 护甲减伤 → 护盾 → 生命

### 0.2 加算 / 乘算规则
    -加算区：所有 op=add 的修饰先相加，再一次性加到基础面板
        面板值 = 基础值 + Σ(add)
    -乘算区：所有 op=mul 的修饰各自以 (1 + value) 连乘
        最终值 = 面板值 × Π(1 + value)
    -先加算，后乘算；两者互不干扰

### 0.3 模块登记表（可插拔）
    | 模块 | 职责 | 落地位置 |
    |---|---|---|
    | Effect 效果系统 | buff / debuff 数据目录（燃烧、磁力） | scripts/effect_data.gd |
    | Effect 运行时 | 层数 / 计时 / 造成与承受伤害系数 | scripts/effect_holder.gd |
    | 装备系统 | 永久属性修饰（加算 / 乘算） | 未实现（原 Modifiers.json 已删除） |
    | 武器系统 | 基础面板倍率换算 + 命中时施加 Effect | scripts/weapon_data.gd |
    | 卡牌系统 | 稀有度概率 + 卡牌修饰项（加算 / 乘算） | scripts/card_data.gd |
    | 道具系统 | 限时 / 立即生效道具目录 + 掉落权重 | scripts/item_data.gd |
    | 物品存储系统 | 背包 20 格（堆叠 99）+ 物品栏 5 格 | scripts/inventory.gd |
    | Boss 系统 | Boss 数值 / 外观 / 技能配置 | scripts/boss_data.gd + scripts/boss_skills/ |

    -元素系统已并入 Effect 目录：火 → 燃烧、磁 → 磁力

## 1. Effect 效果系统

### 1.1 定义
    -Effect：可被施加到角色身上的持续效果，每种 effect 造成不同效果
    -施加正面效果时称为 buff，施加负面效果时称为 debuff
    -同一个 Effect 同时拥有 buff 与 debuff 两套数值，按施加对象决定走哪一套
        buff：增加角色的属性，例如增加伤害，减少伤害，增加元素伤害，减少元素伤害
        debuff：减少角色的属性，例如减少伤害，增加伤害，减少元素伤害，增加元素伤害
    -敌人也是角色，也可以被施加 buff 与 debuff

### 1.2 Effect 数据模板（新增 Effect 复制此模板填写）
    | 字段 | 说明 |
    |---|---|
    | id | 唯一标识，小写英文 |
    | name | 显示名称 |
    | icon | emoji 图标 |
    | max_stacks | 可叠加层数上限 |
    | duration_second | 每层持续时间 |
    | stack_rule | 新层叠加时的计时规则：刷新 / 累加 / 不叠加 |
    | buff_effect | 作为 buff 时每层的效果 |
    | debuff_effect | 作为 debuff 时每层的效果 |
    | trigger | 触发方式：武器触发 / 拾取触发 / 特殊触发 |
    | targets | 可施加对象：玩家 / 敌人 / 双方 |

### 1.3 Effect 目录

#### 1.3.1 燃烧 burn
    UI图标：emoji火焰 🔥
    名称：燃烧
    可叠加层数：buff 上限 10 层；debuff 无上限
    持续时间：每层 10 秒
    叠加规则：施加新层时持续时间重置
    效果：
        作为 buff 时：每层增加 3% 伤害
        作为 debuff 时：每层增加 3% 受到的伤害，每秒造成 武器伤害*火伤害系数*层数 
    触发时造成伤害为：武器伤害*火伤害系数
    伤害飘字显示为：“🔥”+触发时造成的伤害
    施加对象：由武器配置决定

### 1.3.2 磁力 magnet
    UI图标：emoji磁铁 🧲
    名称：磁力
    可叠加层数：10 层
    持续时间：每层 5 秒
    叠加规则：施加新层时持续时间叠加
    效果：
        作为 buff 时：
            1，吸收附近的掉落物（金币，经验球等）
            2，每秒增加 2%*层数的护盾上限（buff 结束时该加成消失）
        作为 debuff 时：
            1，受到磁力 debuff 的敌人会相互吸引，直到距离小于 1 米时停止吸引
            2，失去 3%*层数的护盾，满层时额外失去20%护盾
            3，满层时，敌人被磁力束缚无法移动，直到 debuff 结束（视觉表现：敌人被磁铁图标环绕）
            初始持续 5 秒，后续施加新层时持续时间 +1 秒，时间会叠加
    触发时造成伤害为：武器伤害*磁伤害系数

### 1.3.4 冰冻 freeze
    UI图标：emoji冰冻 ❄️
    名称：冰冻
    可叠加层数：10 层
    持续时间：每层 10 秒
    叠加规则：施加新层时持续时间叠加
    效果：
        作为 buff 时：
            1，增加护盾值
        作为 debuff 时：
            1，受到冰冻 debuff 的敌人减少 9%*层数的移速，同时减少 9%*层数的攻速，受到的暴击伤害增加 10%*层数
            2，满层时，敌人被冻结直到debuff结束（视觉表现：敌人被冰冻图标覆盖）

            
    触发时造成伤害为：武器伤害*冰冻伤害系数

### 1.3.3 碎盾 shatter
    UI图标：emoji 💥
    名称：碎盾
    可叠加层数：1 层
    持续时间：10 秒
    叠加规则：施加新层时持续时间重置
    效果：
        作为 debuff 时：护盾回复延迟 +10 秒
    触发方式：牛头人红圈命中（击碎护盾时施加）
    施加对象：玩家

    （新增 Effect 在 1.3 下追加 1.3.x 小节即可）

### 1.4 施加规则
    -每命中一次按武器「施加概率」结算一次
    -施加概率没有上限：每满 100% 就多施加一次（即多叠一层）
    -多种可施加 Effect 时，同时施加多个 Effect
    -多余概率随机分配给不同的 effect
    -施加 debuff 与施加 buff 的概率分别结算

### 1.5 显示规则
    -玩家：画面底部 buff 栏，每个 Effect 一个图标块，显示 emoji + 名称 + 剩余秒数 + 层数
        buff 为蓝色背景，debuff 为红色背景
    -敌人 / Boss：血条下方显示「emoji 图标 + 层数」（敌人没有血条时显示在身体下方）
    -Boss 血条下方显示全部 Effect（含磁力等 buff）
    -冲刺不是 Effect，只是冷却指示，不参与本系统（仍显示在底部栏）
